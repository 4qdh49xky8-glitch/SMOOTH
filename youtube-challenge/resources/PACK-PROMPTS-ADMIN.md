# Pack gratuit — Prompts « Devis · Factures · Relances »

Fonctionne avec n'importe quel assistant IA généraliste. **Relisez toujours** avant d'envoyer. N'insérez aucune donnée sensible (IBAN, mots de passe). Adaptez au droit et aux mentions légales de votre pays : ce pack n'est pas un conseil juridique ou comptable.

## 1. Devis en 2 minutes
```
Tu es mon assistant administratif. Rédige un devis clair à partir de ce brief client.
Brief : [coller les notes/le mail du client]
Mon activité : [métier] — tarif de référence : [tarif horaire ou forfait]
Structure : 1) contexte en 2 phrases 2) périmètre inclus 3) exclusions 4) livrables et délais
5) prix détaillé en tableau 6) conditions de paiement 7) durée de validité.
Si une information manque, pose-moi d'abord les questions nécessaires au lieu d'inventer.
```
Relecture : prix, délais, exclusions, mentions légales.

## 2. Facture à partir d'un devis accepté
```
À partir de ce devis accepté : [coller]
Génère le contenu de la facture : lignes, quantités, montants HT, TVA si applicable [taux],
total TTC, échéance [date], pénalités de retard selon mes conditions : [coller].
Signale tout champ manquant. Ne devine aucun numéro de facture ni coordonnée.
```

## 3. Relances en 3 étapes (J+3, J+10, J+20)
```
Écris 3 e-mails de relance pour la facture [n°] de [montant] échue le [date].
Ton : 1) courtois (rappel simple) 2) professionnel et précis (rappelle l'échéance et propose une solution)
3) ferme mais respectueux (indique les conditions de retard prévues dans mon contrat).
Chaque e-mail : objet + corps de 80 mots maximum + une action claire.
```
Avant d'utiliser le 3e : vérifier vos conditions contractuelles et la loi locale.

## 4. Réponse rapide à un e-mail client
```
Voici un e-mail client : [coller]. Mon objectif : [répondre / décaler / refuser poliment / demander des précisions].
Rédige 2 versions (courte, détaillée), ton [ton], sans promesse que je n'ai pas confirmée : [contraintes].
```

## 5. Qualifier un prospect
```
Voici le message d'un prospect : [coller]. Pose-moi 5 questions de qualification (besoin, budget, délai,
décideur, contraintes) et résume ce que je sais déjà. Dis-moi si le projet semble adapté à mon offre : [offre].
```
